PRINCIPLE
The project root is reserved for runtime/build configuration, required service config, top-level source folders, and the two copy-over entrypoint BAT files.
All project documentation .md/.txt belongs under document/.

TOOLING
- scripts/android/: Android build/install BAT helpers
- scripts/firebase/: the single canonical home for Firebase deploy helpers
- scripts/maintenance/: maintenance and structure gates
- scripts/setup/: copy-over/setup cleanup logic
- scripts/windows/web/: Windows Web preview/export BAT helpers
- scripts/music/state/: machine state for catalog tooling
- scripts/music/reports/: machine-generated music audit output

ANDROID/WEB ONLY
- GoogleService-Info.plist is not shipped.
- app.json has no active iOS Firebase/bundle config.
- package.json has no ios run script.
- android/ and ios/ generated native folders remain ignored because CNG generates native Android when needed.

RULES
1. No .md or .txt files at root.
2. Do not create a parallel documents/ directory or top-level reports/.
3. Do not place helper BAT files at root unless they are copy-over entrypoints.
4. Do not move Expo/Metro/Firebase config files away from their expected root locations merely for aesthetics.
5. Run npm run structure:check before shipping every FULL build.
