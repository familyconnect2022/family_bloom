Date: 2026-09-29

Scope
1) Background genealogy canvas is immutable while Focus View is open
- Removed legacy in-canvas branch fallback and branch-dimming machinery.
- Opening a branch only builds/opens the Focus View overlay.
- Background viewAnchor, selection, connectors, pan and zoom are not changed by branch open/close.
- Focus View interaction shield still blocks pan/pinch from reaching the background.
- A -> B inside Focus View reuses the same overlay.

2) Default graph entry behavior
- Normal graph always opens in 3-generation mode.
- The linked current user's Person is used only as initial view anchor/camera target.
- The current user's node is highlighted, but no default branch-focus state, relation badges, connector dimming or "Nhánh đang xem" banner is applied.
- Initial selection is empty; the user node is simply centered and highlighted.

3) Focus performance
- Bounded branch visual data still comes from the already-loaded in-memory query engine snapshot.
- Branch visual layouts are cached per {mode}:{personId} for the current query-engine snapshot.
- A real graph snapshot change automatically creates a fresh cache.
- No Firestore listener/query is added for Focus View.

4) Music
- Phase 14E music behavior is unchanged in this patch.
- A preparation note is included for the next curated music-assignment step; no curated track IDs are activated yet.

Deploy impact
- No new Firestore Rules, indexes, Functions or native dependency.
- No native rebuild required solely for Phase 14F when upgrading from Phase 14E.
