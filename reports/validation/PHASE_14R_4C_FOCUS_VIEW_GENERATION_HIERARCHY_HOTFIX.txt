DEVICE ISSUE REPRODUCED
- Main tree correctly shows Nguyễn Vũ Đôn + Nguyễn Thị Lan above their child Nguyễn Thị Bích.
- Focus View opened on a deeper descendant could place Đôn/Lan on the same row as Bích.

ROOT CAUSE
- Focus View reused the standard adapter's bounded generation strategy.
- The tapped focus Person was seeded at generation 3.
- Ancestors above generation 1 were clamped to generation 1.
- With a four-generation chain this collapsed great-grandparents and grandparents onto one visual row.

FIX
- Added opt-in preserveGenerationHierarchy to adaptFamilyGraphSnapshot.
- Standard/main tree keeps the existing bounded behavior unchanged.
- Focus View alone enables preserveGenerationHierarchy.
- Focus branch generations are rebased so the oldest visible generation starts at row 1.
- Every explicit parent_child edge remains exactly one generation apart.
- Focus layout can grow beyond five generations without collapsing different generations onto one row.
- No Firestore schema/read/listener changes.
