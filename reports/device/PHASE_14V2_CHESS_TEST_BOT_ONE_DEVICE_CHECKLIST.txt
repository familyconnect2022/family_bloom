Date: 2026-10-03

PURPOSE
- Test Chess with one Android phone before a second real device is available.
- Bloom Bot is a test harness only. It is NOT Stockfish, not ranked AI, not a real family member.
- It uses the same authoritative server game/clock/persistence path as a real opponent.

A. ENABLE TEST BOT — SERVER IS AUTHORITATIVE
1) Root app .env only needs:
   EXPO_PUBLIC_CHESS_SOCKET_URL=https://family-bloom-chess.onrender.com
2) Render -> family-bloom-chess -> Environment:
   CHESS_TEST_BOT_ENABLED=true
3) Save and redeploy Render latest source.
4) Restart Metro:
   npx expo start --dev-client --clear
5) No expo run:android is required only for this phase.

[ ] Open https://family-bloom-chess.onrender.com/health
[ ] Expect {"ok":true,"chessTestBotEnabled":true}
[ ] Metro logs [ChessDebug] prewake:response ... chessTestBotEnabled:true

C. DELAYED GLOBAL CHALLENGE OVERLAY — ONE PHONE
[ ] Open Chess Lobby.
[ ] Card "Bloom Bot · Đối thủ thử nghiệm" is visible.
[ ] Choose a time control.

D. GAMEPLAY WITH BOT
[ ] White/Black is assigned by server, not fixed by client.
[ ] If Bloom Bot is White, it makes the opening move automatically after ~0.7–1.35s.
[ ] If user is White, make one legal move; Bloom Bot replies automatically.
[ ] Bot never makes an illegal move.
[ ] Board state/turn/revision stay synchronized after repeated moves.
[ ] Server clock continues authoritatively.
[ ] Legal destination hints still work for the human.

E. GLOBAL TURN TOAST
[ ] Make a move, immediately navigate away from Chess board before Bot replies.
[ ] When Bot replies and it becomes your turn, normal Bloom toast appears.
[ ] Copy includes "Đến lượt bạn • Nước N" or check-specific copy.
[ ] Tap toast -> returns to exact active Chess game.

F. BATTLE FX
[ ] Capture -> lightweight capture FX/copy.

[ ] Check -> "CHIẾU!" treatment.

[ ] Resign -> authoritative result saved normally.
[ ] Finished game -> Chơi lại before 22:00 creates a NEW test game.
