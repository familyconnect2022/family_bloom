- Test Chess with one Android phone before a second real device is available.

A. ENABLE TEST BOT
1) Root app .env:
   EXPO_PUBLIC_CHESS_SOCKET_URL=https://family-bloom-chess.onrender.com
   EXPO_PUBLIC_CHESS_TEST_BOT_ENABLED=true
2) Render -> family-bloom-chess -> Environment:
   CHESS_TEST_BOT_ENABLED=true
3) Redeploy Render latest source.
4) Restart Metro only:
   npx expo start --dev-client --clear
5) No new native dependency was added; expo run:android is not required only for this phase.
